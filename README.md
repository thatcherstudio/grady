# Grady

Run a prompt suite against any OpenAI-compatible model endpoint (Ollama, vLLM, MLX, LM Studio
or hosted), score each answer against what you expected, and see quality next to speed.

**Status:** under construction. See [SPEC.md](SPEC.md) for the design and the milestone issues
for progress. [BUILD_LOG.md](BUILD_LOG.md) records how it is being built.
